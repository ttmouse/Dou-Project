# D-007：使用事件驱动的项目最近活动时间

- 日期：2026-09-20
- 状态：已实现第一阶段

## 决策

项目列表的“修改时间”排序改为读取持久化的 `Project.activityAt`。该字段初始回退到项目目录的 `mtime`，收到 `FSEvents` 变更路径后，仅更新命中的项目，不递归扫描项目文件。

## 原因

递归计算目录内最新文件时间会在列表刷新和排序时产生不可接受的 I/O；事件驱动可以把成本限制在发生变化的项目，并通过现有缓存持久化。

## 当前边界

Git 最近提交时间和后台定期校准尚未接入。后续可在后台任务中补充，不应放入 SwiftUI 渲染或排序路径。
