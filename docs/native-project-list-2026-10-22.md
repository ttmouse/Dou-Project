# 原列表行改为 AppKit 绘制 · 2026-10-22

## 改动范围

沿用 `ProjectListRowsView` 及原表头、排序入口、列宽、42 点行高。搜索和浏览共用同一个列表，不创建第二套搜索列表，也不因搜索切换用户选择的网格/列表模式。

- `NativeProjectListRow` 直接绘制项目名、活动时间、提交数和选中/悬停背景。
- 操作图标为原生 NSButton；标签为自绘外观的 NSButton，并保留悬停移除按钮和 NSScrollView 横向滚动。
- 保留单击与 Command/Shift 多选；拖拽使用原来的 public.data + UUID 集合 JSON，兼容标签投放。
- 右键菜单保留编辑器、终端、编辑标签、刷新和重命名，并将菜单绑定到打开时的项目，防止行复用后误操作其他项目。
- 编辑标签、重命名和启动端口冲突弹层放在列表层，继续调用原有业务组件。
- 行内容不再包含 NSHostingView；表头和弹层仍是 SwiftUI。

## 搜索范围

用户明确选择普通搜索只匹配项目名。索引与 `ProjectLogic` 的纯筛选同步移除路径匹配。输入 dou 不再因用户名而匹配所有项目；真实窗口验证得到 7 个名称匹配项目，网格与列表一致。

## 性能证据边界

采样后自动化出现 AX 窗口无法解析、ScreenCaptureKit -3811。主线程 sample 显示正常等待事件，尚不能据此归因于应用或系统。已停止采样，正常退出并重新打开 App，不进行权限重置。
