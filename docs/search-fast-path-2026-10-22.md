# 原项目列表渲染调整 · 2026-10-22

## 当前实现

- 保留用户原有 `ProjectListRowsView` 的表头、列宽、42 点行高和完整 `ProjectListRow`。
- 列表容器从 `ScrollView` + `LazyVStack` 换为 `NSTableView`，可见行通过 `NSHostingView` 承载原行内容。
- 保留原行的标签滚动、标签点击/删除、运行/编辑器/访达按钮、单击详情、修饰键多选、拖拽、右键菜单和弹层逻辑。
- 按项目 UUID 区分复用行的 SwiftUI 状态，避免重用时把弹层、悬停等状态带给另一个项目。
- 项目 ID 顺序或集合变化才重新加载表格；标签、颜色、选择和 Git 元数据变化只更新可见行。
- 搜索只过滤结果，始终使用用户选定的网格或列表模式。已移除强制切换列表的搜索分支。
- 没有独立的搜索列表实现；网格沿用现有 `ProjectGridView`。

这次不是整行自绘。原行 UI 及操作保持原实现，原生表格仅负责行复用与滚动。
原行视图、表头和选择逻辑已与备份逐字比对。
