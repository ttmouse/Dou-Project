# Editor brand icon sources

The SVG files in this folder are monochrome-rendered brand marks used to identify the corresponding editor in the open-with menu.

- `cursor.svg`, `ghostty.svg`, `sublimetext.svg`, `trae.svg`, and `codebuddy.svg` come from [Simple Icons](https://github.com/simple-icons/simple-icons), CC0 1.0. See `SimpleIcons-LICENSE` and `SimpleIcons-DISCLAIMER.md`.
- `vscode.svg` comes from [Devicon](https://github.com/devicons/devicon), MIT. See `Devicon-LICENSE`.
- `antigravity.svg` comes from [Lobe Icons](https://github.com/lobehub/lobe-icons), MIT. See `LobeIcons-LICENSE`.

The upstream library licenses cover their respective project files. Product names and brand marks remain the property of their owners; the marks are used only to identify the associated applications.
